# LP-MAGIA-1 — Bursztynowa Komnata (Magia Złota)

Landing page produktu "Bursztynowa Komnata" — pierwszej monety z kolekcji "Magia Złota", oparta na treści z:
https://www.azaurum.com.pl/a/kolekcja-magia-zlota

Zbudowana na bazie sprawdzonej struktury projektu `LP-test1HZE`, z paletą przekolorowaną z chłodnego złota na ciepły bursztyn/miedź, dopasowaną tematycznie do Bursztynowej Komnaty.
